Ubuntu Server 制作 OpenOnload DKMS 驱动安装包及安装教程

Ubuntu 22.04 Server 系统制作 onload DKMS 驱动安装包并安装指南

Ubuntu 22.04 LTS (Jammy) OpenOnload 9.1.0.24 x86_64

教程概述

  • ● 本教程介绍如何在 Ubuntu 22.04 Server 系统上，从 Debian 源码包制作 onload DKMS 驱动安装包（.deb），并完成安装。
  • ● OpenOnload 是 AMD Solarflare 网卡的用户态网络加速框架，通过内核旁路技术实现超高吞吐和低延迟网络通信。
  • ● 源码包：onload_9.1.0.24-debiansource.tgz，版本 9.1.0.24-1，适用于 amd64 架构。
  • ● 全程需要 root/sudo 权限，安装完成后通过 DKMS 实现内核模块的自动管理。
  • ● 当前系统内核：6.8.0-138-generic（同时兼容 5.15.0-191 / 6.2.0-39）。

1
解压源码包

将下载的 Debian 源码压缩包解压到当前工作目录，释放出构建所需的 .dsc、.tar.xz 和 .orig.tar.gz 文件。

Terminal — 解压源码 
ps@TestOS:~$ tar -xvf onload_9.1.0.24-debiansource.tgz
./onload_9.1.0.24-1.debian.tar.xz
./onload_9.1.0.24.orig.tar.gz
./onload_9.1.0.24-1.dsc

ps@TestOS:~$ ls
AweSun       Desktop    gpu-burn.zip         onload_9.1.0.24-1.dsc             snap             yc.sh
check_V5.sh  Downloads  mount_V6.sh          onload_9.1.0.24-debiansource.tgz  Templates
deb          gpu-burn   onload_9.1.0.24-1.debian.tar.xz  onload_9.1.0.24.orig.tar.gz  upload_check.sh
i 解压后会生成三个文件：.dsc（Debian源码描述文件）、.orig.tar.gz（原始源码）、.debian.tar.xz（Debian补丁与打包脚本）。
2
展开 Debian 源码目录

使用 dpkg-source 工具根据 .dsc 描述文件自动展开源码目录，生成完整的构建树 onload-9.1.0.24/。

Terminal — 展开源码 
ps@TestOS:~$ sudo dpkg-source -x onload_9.1.0.24-1.dsc
dpkg-source: warning: extracting unsigned source package (onload_9.1.0.24-1.dsc)
dpkg-source: info: extracting onload in onload-9.1.0.24
dpkg-source: info: unpacking onload_9.1.0.24.orig.tar.gz
dpkg-source: info: unpacking onload_9.1.0.24-1.debian.tar.xz

ps@TestOS:~$ cd onload-9.1.0.24/
ps@TestOS:~/onload-9.1.0.24$
i warning 提示源码包未签名，属于正常现象，不影响编译和安装。

4
制作 DEB 安装包

在源码目录中使用 dpkg-buildpackage 执行完整编译，制作 .deb 二进制安装包。编译过程包括内核模块和用户态库。

Terminal — 制作安装包 
ps@TestOS:~/onload-9.1.0.24$ sudo dpkg-buildpackage -us -uc -b

dpkg-deb: building package 'onload-user' in '../onload-user_9.1.0.24-1_amd64.deb'.

i 参数说明：-us 不签名源码包，-uc 不签名变更文件，-b 仅构建二进制包。编译完成后在上级目录生成 .deb 文件。
i 编译可能需要数分钟，取决于 CPU 性能。如遇到缺少头文件错误，请确认已安装对应内核的 linux-headers 包。

安装总结

  • ● 安装完成后，系统将拥有 onload-user（用户态库）和 onload-dkms（内核模块）两套组件。
  • ● 内核模块 sfc.ko / sfc_char.ko / sfc_resource.ko / onload.ko 已编译签名并安装至 /lib/modules/$(uname -r)/updates/dkms/。
  • ● DKMS 会在后续内核更新时自动重新编译模块，无需手动干预。
  • ● 可使用 onload_toolload 或 ef_named_cpool_test 等工具验证功能正常性。

重置系统密码

忘记 root / 普通用户密码时的恢复流程（Ubuntu / CentOS / Rocky）
本手册面向系统测试工程师，讲解忘记系统密码后如何在不重装系统的情况下恢复：涵盖 Ubuntu/Debian（GRUB 单用户救援模式）与 CentOS/Rocky（rd.break 或 init=/bin/sh）两种主流路线，以及常规改密命令。所有需要执行的命令都带一键复制。请遵守所在组织对服务器管理的授权规定，仅在本人有权管理的机器上操作。

1. Ubuntu 22.04 重置密码

进入 GRUB 单用户（救援）模式

Ubuntu 无法直接进单用户模式，需要在 GRUB 启动菜单里编辑内核引导参数，追加 single（或 init=/bin/bash），让内核以单用户方式启动。

text
1. 选择要启动的内核，按 e 进入编辑
2. 找到 linux ... 那行（以 linux /boot/vmlinuz 开头）
3. 在行尾追加： single  （或 init=/bin/bash）
4. 按 Ctrl+X 或 F10 启动
解释：在 GRUB 菜单按 e 编辑；single 让内核进入单用户；init=/bin/bash 则以 bash 作为 init 直接启动 shell。若开机没看到 GRUB 菜单，启动瞬间按住 Shift（传统 BIOS）或连按 Esc/F1（UEFI 部分机型）唤出。

挂载并修改密码

进入单用户/救援 shell 后，根文件系统此时通常是只读（ro）挂载，需先 mount -o remount,rw / 改成读写，再用 passwd root 设新密码（注意 Ubuntu 默认限制 root 登录，若你只记得普通用户则改其用户名）。改完 mount -o remount,ro / 再重启。

bash
mount -o remount,rw /
passwd root
# passwd 用户名
sync
reboot
解释：mount -o remount,rw / 把根文件系统改为可写（改密码必须要写 /etc/shadow）；passwd root 设置 root 新密码；reboot 重启进入正常系统。若提示 Authentication token manipulation error，多半是还没成功 remount 为 rw。

2. CentOS / Rocky / RHEL 重置密码

rd.break 方法

RHEL 系（含 CentOS 7+、Rocky）常用 rd.break：在内核参数末尾追加该参数并 Ctrl+X，会进入一个临时 shell；此时根分区挂载在 /sysroot 下，需 chroot 后改密码。

text
1. 选择内核，按 e 编辑
2. 在 linux16 / linux 行末追加： rd.break
3. 按 Ctrl+X 启动
bash
chroot /sysroot
# mount -o remount,rw /sysroot
# chroot /sysroot
passwd root
touch /.autorelabel
exit
reboot
解释：chroot /sysroot 切换到真实根文件系统目录才能操作；passwd root 改密码；touch /.autorelabel 让 SELinux 下次启动自动重新标记（避免因密码/文件上下文改变导致无法登录），最后 exit 退出 chroot、reboot 重启。

init=/bin/sh 方法

若 rd.break 不生效（部分版本/云镜像差异），改用 init=/bin/sh 直接以 bash 作为 init 进入单用户 shell。

text
1. 按 e 编辑目标内核
2. 在 linux16 / linux 行末追加： init=/bin/sh
3. 按 Ctrl+X 启动
bash
mount -o remount,rw /
passwd root
touch /.autorelabel
reboot
解释：与 Ubuntu 类似，用 init=/bin/sh 直接进入单用户 bash；mount -o remount,rw / 写根分区；passwd root 改密；touch /.autorelabel 供 SELinux；最后 reboot。个别环境 reboot 不可用时可 exec /sbin/init

3. 修改密码通用命令

passwd / chpasswd

进入系统后修改密码最常用 passwd（交互式）和 chpasswd（非交互，适合批量/脚本）。

bash
passwd
sudo passwd root
echo 'root:NewPass123' | sudo chpasswd
sudo chpasswd < userpass.txt
解释：passwd 交互让输入两次新密码；chpasswd 从 stdin 读取 用户名:密码 行批量设置，适合脚本/多机。注意不要让密码出现在 shell 历史中，脚本用后及时清理。

忘记密码后的安全提醒

安全与授权提醒
  • 重置密码会破坏原密码，操作前确认是本人/本组织有权管理的机器，避免影响他人使用。
  • 用救援/单用户改密后，务必处理 SELinux（/.autorelabel）与磁盘只读问题，避免重启后无法登录。
  • 生产机改密建议先在维护窗口执行，改完立即测试能否登录，并及时同步给相关的同事/运维。
  • 避免长期使用弱密码或说密码明文暴露；有运维平台/带外管理（IPMI）的机器也可考虑通过 BMC 远程 KVM 进单用户改密。

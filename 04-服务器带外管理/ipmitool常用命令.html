IPMI 管理工具

ipmitool 常用命令详解 · 硬件状态 / 电源控制 / 远程运维
本手册面向系统测试工程师，讲解 BMC（基板管理控制器）的标准管理命令行工具 ipmitool：环境准备、传感器/硬件状态查看、开机关机重启、远程串口与网络运维、SEL 事件日志。所有命令带一键复制并逐个解释。本地机器直接使用，远程机器加 -H IP -U 用户 -P 密码 即可。

1. 环境准备与连接方式

安装 ipmitool

大多数 Linux 发行版软件源里都有 ipmitool，一条命令即可安装。装完后用 ipmitool mc info 验证能否和本机 BMC 通信。

bash
# CentOS / RHEL / Rocky
sudo yum install ipmitool -y

# Ubuntu / Debian
sudo apt install ipmitool -y

# 验证是否能读到本机 BMC
ipmitool mc info
解释：mc info 读取本机 BMC 的固件/型号/制造商信息。若提示 Error: Unable to open 或没有 /dev/ipmi0，先加载内核模块：sudo modprobe ipmi_si ipmi_devintf（需 root）。

本地接口 / 远程接口

ipmitool 支持两种使用方式：本地直连 BMC 通道（-I open），以及通过管理网口远程连另一台机器的 BMC（-I lanplus + 主机/IP/用户/密码）。

bash
# 本地直连（本机 BMC）
ipmitool -I open power status

# 远程连接（通过管理口连另一台机器 BMC）
ipmitool -I lanplus -H 192.168.1.100 -U admin -P password power status

# 参数简写示例（省去 -I，默认 lanplus 会省略部分下）
ipmitool -H 192.168.1.100 -U admin -P password sensor list
解释：-I open 本地内核通道；-I lanplus 远程 RMCP+ 加密通道（推荐）；-H BMC 管理口 IP；-U/-P 用户名/密码。把 192.168.1.100 / admin / password 换成实际值。远程管理口需先配置网络，见第 4 章。

2. 传感器与硬件状态

电源 / 电源状态

快速确认机器当前是否通电、开机，以及风扇、电源等关键传感器读数。测试中常先看电源状态再决定下一条命令。

bash
# 查看当前电源状态（on / off）
ipmitool power status

# 查看电源信息（PSU，输入输出、状态）
ipmitool sdr type "Power Supply"
# 或直接列出传感器并筛选电源相关
ipmitool sensor list | grep -i power
解释：power status 返回机器通电状态（非 OS 运行状态）；sdr type 按类型过滤传感器数据记录；sensor list 列出所有传感器并可 grep 筛选。电源状态主要用于确认 KVM/IPMI 下机器是否已上电。

传感器列表与实时读数

温度、电压、风扇转速、机箱侵入等传感器是硬件健康排查的第一站。可整表输出，也可按类型/名称定向查找。

bash
# 列出全部传感器（名称、读数、状态、阈值）
ipmitool sensor list

# 只看温度类
ipmitool sensor list | grep -i temp

# 只看风扇类
ipmitool sensor list | grep -i fan

# 用 sdr 更紧凑地查看关键健康项
ipmitool sdr list
# 直接读指定传感器当前值
ipmitool sensor get "CPU Temp"
解释：sensor list 显示所有传感器当前读数与告警状态（ok/nr/cr/lnc inc 等）；sdr list 只汇总当前状态（Compact）；sensor get 查看单个传感器详情含上下阈值。温度过高、风扇转速过低都会在这体现。

FRU 与系统信息

FRU（现场可更换单元）记录硬件序列号、厂商、部件号，用于资产登记与保修排查。

bash
# 查看所有 FRU 信息（主板/机箱/产品序列号等）
ipmitool fru print

# 查看 BMC 自身信息
ipmitool mc info
# 查看本机系统/主机名等（依赖系统实现）
ipmitool chassis status
解释：fru print 输出 FRU 设备的序列号与厂商；mc info 看 BMC 固件版本——在排查 BMC 问题时首先要确认的；chassis status 汇总机箱上电、开机按钮、告警状态。

3. 开机关机与重启

电源控制命令

通过 ipmitool 控制机器上电/关机/重启，在执行压测/故障复现、远程整机时非常常用。所有电源命令都属远程高影响操作，务必看清机器身份后再执行。

bash
# 开机（ACPI 软开机）
ipmitool power on
# 关机（ACPI 软关机）
ipmitool power off
# 强制重启（冷重启，类似按 Reset 键）
ipmitool power reset
# 软重启（与 reset 类似，立即循环）
ipmitool power cycle
# 查看当前状态
ipmitool power status
注意：power off 是关机，power reset 是冷重启（会先断电再上电），power cycle 也是断电再上电但可能进行 ACPI 软关。执行开关机命令前先 power status 确认当前机器，避免误操作在跑的机器。

开机引导设备设置

测试时经常需要设置下一次开机从 U 盘、光驱或 PXE 引导，便于装系统或进诊断环境。

bash
# 设置下一次引导设备（这里用 PXE；一次有效）
ipmitool chassis bootdev pxe

# 设为从光驱引导
ipmitool chassis bootdev cdrom
# 设为正常从硬盘引导
ipmitool chassis bootdev disk
# 查看当前引导设备设置
ipmitool chassis bootparam get 5
解释：chassis bootdev 设置下一次/持续引导目标（pxe/cdrom/disk/bios 等）；用 bootparam get 5 查看当前设置。多数板卡该设置「下一次开机生效」，装完系统后记得改回 disk，否则可能反复从 PXE 引导。

4. 网络与远程运维

远程 SOL 串口

SOL（Serial Over LAN）让你在 OS 未起来、甚至 BIOS 阶段也能看到控制台输出，是远程排障的利器。需先在 sol activate 前确认 BIOS/BMC 已启用 SOL。

bash
# 激活远程串口控制台（连上后即可看到 BIOS/串口输出）
ipmitool -I lanplus -H 192.168.1.100 -U admin -P password sol activate

# 设置转义字符为 ~（避免与普通按键冲突）后再次进入
ipmitool -I lanplus -H 192.168.1.100 -U admin -P password \
  -e '&' sol activate

# 退出 SOL：先按 ~ 再按 . 即可断开（Ctrl+］ 为候选转义）
解释：sol activate 建立远程串口会话，看到的是该机串口控制台输出（需 OS/BIOS 串口重定向已开启）。退出会话一般按 Ctrl+］ 再输入 ~.。-e 指定转义字符避免与普通字符冲突。无输出时先确认 BIOS 的 Serial Console 重定向已配置。

查看/管理网络设置

BMC 管理口的 IP、子网、网关、用户权限等可通过 lan 子命令查看或修改。首次部署或地址冲突时常用。

bash
# 查看通道1的 LAN 配置（IP/掩码/网关/MAC）
ipmitool lan print 1

# 设置 BMC 静态 IP（示例，值按实际替换）
ipmitool lan set 1 ipaddr 192.168.1.100
ipmitool lan set 1 netmask 255.255.255.0
ipmitool lan set 1 defgw ipaddr 192.168.1.1

# 查看所有通道状态
ipmitool channel info
注意：修改网口 IP 时若从该口远程连接会立即断开；改通道 1 的网络参数前先记录原值。多数服务器默认 DHCP 或固定地址，务必与网管协调。改完可 lan print 1 复查。

SEL 事件日志

SEL（System Event Log）记录开机以来的告警、温度越界、电源异常等事件，是排查整机健康迹的关键依据。

bash
# 查看全部事件日志
ipmitool sel list

# 只显示发生告警/状态的摘要
ipmitool sel elist

# 清空事件日志（排查前先备份再看）
ipmitool sel clear

# 监控新事件（持续输出，Ctrl-C 退出）
ipmitool sel time get
解释：sel list 打印所有事件（时间/类型/severity）；sel elist 是紧凑版；sel clear 清空日志（先备份，如 sel list > sel_backup.txt）。常见的电源、温度、风扇事件会在 SEL 留下记录，结合传感器一同判断故障根因。

5. BMC 用户与密码管理

通过 ipmitool 可查看、新增、修改、删除 BMC 用户，并重置用户密码——忘记 BMC 登录口令时尤其实用。命令使用 /user 子命令与用户 ID 配合操作（BMC 用户以数字 ID 标识），多数操作需用管理员权限（如默认的 admin 用户）执行。

查看现有用户

先列出所有用户及 ID，拿不准自己 ID 时先查一遍；同时可用 user list 看权限级别与启用状态。

bash
# 查看本机 BMC 的全部用户（ID、用户名、权限、是否启用）
ipmitool user list

# 远程查看（把 IP/用户/密码换成您的）
ipmitool -I lanplus -H 192.168.1.100 -U admin -P password user list
解释：user list 输出每行一个用户，列通常包含 ID、Name、Callin、Link Auth、IPMI Msg、Channel Priv Limit。其中 ID 是后续所有用户操作的关键；权限等级 A=Administrator（管理员）、O=Operator、U=User。

新增 / 修改 / 删除用户

新增用户需先分配一个空 ID（一般从 3 开始预留 admin 固定 ID 2），再设用户名与密码，最后指定权限并启用。

bash
# 新建用户：使用 ID 3（2 常为 admin），设用户名 ops
ipmitool user set name 3 ops

# 为该用户设置初始密码
ipmitool user set password 3 'Ops@2026!'

# 授予管理员权限（权限 4 = Administrator）
ipmitool user priv 3 4
# 或授予普通用户权限（权限 3 = User，2 = Operator）
# ipmitool user priv 3 3

# 启用该用户（默认可能为禁用）
ipmitool user enable 3

# 校验：再列出一次确认新增成功
ipmitool user list
解释：user set name <ID> <用户名> 设用户名；user set password <ID> '新密码' 设密码；user priv <ID> <权限> 指定权限（1-回调/2-用户/3-操作员/4-管理员，Channel 权限另设）；user enable 启用。删除用户：ipmitool user disable <ID>（BMC 通常只支持禁用，不支持物理删除）。

修改用户名 / 密码

忘记 BMC 密码时，用能登录的 admin 账号直接重设指定用户的密码即可，不必整卡复位；也能顺带改名。

bash
# 重置指定用户（这里 ID 2 = admin）的密码
ipmitool user set password 2 'NewAdmin@2026!'

# 修改用户名（把 ID 2 改为 newadmin；需先知道旧名）
ipmitool user set name 2 newadmin

# 若忘记所有 BMC 账号：先查看存在的用户 ID
ipmitool user list

# 部分 BMC 支持通过系统态平台命令直接重置 admin 密码（依厂商而定）
# ipmitool user set password 2 'NewPass' --overwrite? 参考具体硬件说明
注意：
  • user set password <ID> 会覆盖原密码，误操作可能导致其它人无法登录，改前先 user list 确认 ID。
  • 忘记 BMC 密码通常无法直接通过 OS 内的 ipmitool 绕过（需带外 BMC 登录或厂商工具/硬件复位）。若你仍有 admin 权限或厂商默认口令则可重置；否则一般需联系厂商通过专用流程恢复。
  • 修改密码后，正在使用的远程会话可能失效，请用新口令重新连接测试。
